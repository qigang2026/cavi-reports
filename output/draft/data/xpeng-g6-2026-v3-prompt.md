# CAVI 购车解读报告生成 Prompt v2.1（多动力兼容版）

## 概述

本 Prompt 用于指导 AI 生成 AutoCava CAVI 购车解读报告（HTML 单文件，PC + H5 自适应）。
支持三种动力类型：**纯电（EV）/ 混动（HEV/PHEV）/ 燃油（ICE）**。

---

## 一、基本原则

1. **不向用户提问**，直接生成标准版报告。
2. **直接使用提供的 CAVA 指数**，不要重新计算或创造第二套评分。
3. **所有车型参数、价格、金融方案、口碑、质保、用车成本和经销商数据必须以输入数据为准**。
4. **没有提供的数据不要编造**：
   - 重要字段缺失时显示"待确认"或"数据来源：需人工确认"；
   - 非重要字段缺失时隐藏对应内容；
   - 不要用看似真实的示例数字填充。
5. **金融机构 Logo** 只能展示在已经明确对应具体金融产品时，不能给普通测算方案随意添加金融机构 Logo。
6. **竞品车系中不展示中国品牌**。
7. **页面文案必须面向普通消费者**，避免出现"接口读取、后台数据、库内字段、筛选口径、内部计算、二次造分"等内部术语。
8. **页面使用中文**，金额使用 MXN，数字使用千位分隔符。
9. **页面必须同时适配桌面端与移动端**（一份 HTML + `@media` 覆盖双尺寸）。
10. **输出完整、可直接运行的单文件 HTML**，CSS 和必要的 JavaScript 都写在同一个文件中。
11. **最终只输出 HTML 代码**，不要在代码前后增加解释。

---

## 二、动力类型分支处理（核心）

AI 必须根据输入 JSON 中 `powertrainType` 字段判断车型动力类型，并按对应规则生成：

### 2.1 动力类型识别

| 字段值 | 类型 | 处理逻辑 |
|--------|------|----------|
| `"EV"` | 纯电 | 走"电费 / 续航 / 800V"分支 |
| `"HEV"` | 油电混动（非插电） | 走"油耗 / 油电协同"分支 |
| `"PHEV"` | 插电混动 | 同时走"电费 + 油耗"双分支 |
| `"ICE"` | 燃油 | 走"纯油耗"分支 |

### 2.2 各动力类型必备字段

**纯电（EV）必备：**
- `specs.rangeKm`（续航）、`specs.batteryKwh`（电池容量）、`specs.electricConsumptionKwh100Km`（百公里电耗）
- `ownershipCost.electricity.*`（电价、年充电费）
- 可选：`specs.voltagePlatform`（800V 等高压平台）、`specs.chargeTimeNote`

**燃油（ICE）必备：**
- `specs.engineDisplacementMl`（排量）、`specs.fuelConsumptionL100Km`（百公里油耗）、`specs.fuelConsumptionKmL`（km/L 倒推）
- `ownershipCost.fuel.*`（油价、年油费）
- 可选：`specs.tankCapacityL`（油箱容量）、`specs.rangeKm`（油箱续航）

**混动（HEV/PHEV）必备：**
- 同时具备 `fuel.*` 和 `electricity.*` 两组字段
- PHEV 必须有 `specs.batteryKwh` 和 `specs.electricRangeKm`（纯电续航）
- HEV 可无 `batteryKwh`（无需外接充电）

### 2.3 报告模块的条件渲染

| 模块 | EV | ICE | HEV/PHEV |
|------|----|----|----------|
| **Hero 核心数据 3 项** | 续航 / 高压平台 / 后备厢 | 油耗 / 功率 / 后备厢 | 纯电续航 / 综合油耗 / 后备厢 |
| **用车成本 - 电费卡** | ✅ 显示 | ❌ 隐藏 | ✅ 显示 |
| **用车成本 - 油费卡** | ❌ 隐藏（显示"同级燃油参考"） | ✅ 显示 | ✅ 显示 |
| **能源费用差对比** | ✅ 电 vs 油 | ❌ 跳过 | ❌ 跳过 |
| **价格走势图表** | ✅ 价格走势 | ✅ 价格走势 | ✅ 价格走势 |
| **避坑指南 - 充电条件** | ✅ 必须包含 | ❌ 隐藏 | ⚠️ 视情况 |
| **避坑指南 - 续航虚标** | ✅ CLTC | ⚠️ 油耗工况 | ✅ CLTC 电 + 综合油 |

## 三、报告结构（必含 8 大板块）

### 板块 0：报告元信息（Header）
- 顶部品牌 Logo（指向 autocava.com.mx）
- 主导航（#block1~#block4 + #contacto）
- 分享按钮
- 数据新鲜度提示（根据 publishDate + expireDays 动态计算）

### 板块 1：Hero（封面）
- 品牌 + 车系 + 具体版本
- 车型官方图片（hero 大图）
- CAVA 综合评分 + 评分人数
- 一句话购车结论
- 车型整体概述（2-3 句话）
- 3 个最重要的核心数据：
  - **EV**：续航（如 CLTC 510 km）/ 高压平台（800 V）/ 后备厢（571 L）
  - **ICE**：油耗（如 5.32 L/100km）/ 功率（118 hp）/ 后备厢（466 L）
  - **HEV/PHEV**：纯电续航 / 综合油耗 / 后备厢
- 适用场景 3 类标签：**非常适合 / 视情况 / 需要考虑**

### 板块 2：帮我省钱（#block1，绿色主题）
- 当前参考车价 + 促销价（如有）
- 2 个金融产品对比（MStar / BBVA / Banorte 等）：
  - 机构 Logo、机构名称、产品名称
  - 月供、首付（比例 + 金额）、期限、年利率
  - 适用人群 + 方案特点
- 全年基础使用成本：
  - **公式**：能源费（电/油）+ 年均保养 = 全年合计
  - 月均成本
- 能源费用明细卡：
  - **EV**：百公里电耗 / 电价 / 年充电费 + 同级燃油参考对比 + 年度能源费用差
  - **ICE**：百公里油耗 / 油价 / 年油费
  - **HEV/PHEV**：百公里电耗 / 电价 / 年充电费 + 百公里油耗 / 油价 / 年油费
- 保养费用 4 格：
  - 年均保养 / 前 5 年年均 / 5 年计划保养标价 / 权益后支出
- 10 年计划保养序列（横滚展示）
- 价格走势折线图（ECharts，6 个月数据）

### 板块 3：让我安心（#block2，蓝色主题）
- CAVA 口碑评价：
  - 综合评分 + 进度条 + 评分人数
  - 主要认可 / 更适合人群 / 需要关注（3 个 dim card）
- 购车保障（2×2 网格）：
  - 整车质保 / 高压电池（EV/PHEV）/ 车身质保 / 道路救援
- 当前购车权益：
  - 限时权益 1：保养包含
  - 限时权益 2：保险赠送
- 服务网点：
  - 经销商数量 / 覆盖城市 / 查看附近按钮

### 板块 4：助我省时（#block3，紫色主题）
- 适用场景判断（5 张卡片：1 个引导 + 4 个判断）：
  - 强 / 强 / 条件 / 弱
- 主要竞品怎么选（3 张对比卡：1 本车 + 2 竞品）：
  - 品牌、车型、价格区间、月供
  - 适合人群、主要优势、注意事项
  - 车系详情链接
- 核心参数速览（4 列 stats row）：
  - **EV**：续航 / 功率 / 电池 / 高压平台
  - **ICE**：排量 / 功率 / 油耗 / 油箱容量
  - **HEV/PHEV**：纯电续航 / 综合功率 / 电池 + 综合油耗
- 生活方式分割（图文并茂）

### 板块 5：避坑指南（#block4，橙色主题）
- 6 个避坑卡片（按动力类型动态选择）：
  - **EV 必有**：家充条件 / 续航虚标 / 800V 配套充电桩
  - **ICE 必有**：城市拥堵油耗 / 燃油价格波动 / 维保便利性
  - **HEV/PHEV**：家充 + 油耗 / 模式选择 / 电池质保
  - **通用**：服务网点 / 金融方案月供≠落地成本 / 保值率
- 一句话总结

### 板块 6：底部 CTA（#contacto）
- 3 个并列按钮：获取购车方案 / 预约试驾 / WhatsApp 咨询
- 链接使用 `links.*` 中提供的真实 URL

### 板块 7：Footer
- 数据免责声明
- 车型详情 / 品牌官网 / 服务网点链接

### 板块 8：悬浮组件
- Cavi 助手（自动弹出，显示竞品卡片）
- WhatsApp 浮动按钮（H5 专属）
- 分享弹层（WhatsApp / Facebook / Messenger / 复制链接）

## 四、视觉设计规范

1. **整体风格**：AutoCava 数据研究报告风格（编辑感 / 研究报告感 / 汽车品牌官网质感）。
2. **主色**：
   - 深海军蓝 `#0a1929`（主背景/导航）
   - 金黄色 `#d4a41a` / `#FFC422`（强调色）
   - 白色 `#FFFFFF`（卡片背景）
   - 浅灰 `#f7f8fa`（板块分隔背景）
3. **板块主题色**（4 个核心板块）：
   - 帮我省钱 → 翡翠绿 `#059669`
   - 让我安心 → 深蓝 `#1E40AF`
   - 助我省时 → 琥珀橙 `#D97706`
   - 避坑指南 → 珊瑚红 `#E11D48`
4. **设计原则**：大字号结论、清晰的数据卡片、官图、充足留白。
5. **不使用**：花哨渐变、卡通图标、互联网模板化设计。
6. **金融机构 Logo**：白底区域展示，保持原始比例，不拉伸。
7. **车型图片**：透明背景车系图优先（`https://cdn.autocava.com.mx/car/series/*.png`）。
8. **响应式**：H5（max-width: 768px）所有多列卡片自动变单列。
9. **图片 alt**：所有图片必须包含 alt 属性。
10. **外链**：外部链接使用 `target="_blank" rel="noopener"`。
11. **品牌 Logo**：`https://cdn.autocava.com.mx/_nuxt/asset/logo.v3.mLItLIXo.svg`

## 五、风险提示（Footer 必含）

页面最下方保留简短说明：
- 价格、金融方案、权益及能源价格可能变化；
- 金融方案以金融机构审批为准；
- 实际能耗受到路况、温度、驾驶习惯和充电条件影响；
- 最终交易条件以购车时确认为准。

## 六、数据输入格式

请按以下 JSON 结构提供数据（参见 `xpeng-g6-2026-v3-schema.json`）：

```json
{
  "report": { ... },
  "vehicle": { ... },
  "cava": { ... },
  "price": { ... },
  "financePlans": [ ... ],
  "priceTrend": { ... },
  "specs": {
    "powertrain": { ... },
    "energy": { ... },
    "dimensions": { ... }
  },
  "ownershipCost": {
    "energyType": "electricity | gasoline | hybrid",
    "electricity": { ... } | null,
    "fuel": { ... } | null,
    "maintenance": { ... }
  },
  "warranty": [ ... ],
  "benefits": [ ... ],
  "service": { ... },
  "scenarios": [ ... ],
  "competitors": [ ... ],
  "pitfalls": [ ... ],
  "pitfallSummary": { ... },
  "footer": { ... }
}
```

### 关键字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `powertrainType` | enum | `EV` / `HEV` / `PHEV` / `ICE`，决定渲染分支 |
| `energyType` | enum | `electricity` / `gasoline` / `hybrid`，决定用车成本主路径 |
| `electricity` | object\|null | 仅 EV/PHEV 填，包含百公里电耗/电价/年充电费 |
| `fuel` | object\|null | ICE/HEV/PHEV 填，包含百公里油耗/油价/年油费 |
| `pitfalls` | array | 按动力类型选择 6 个避坑卡片 |
