# _demo/

**Demo 数据样例**。这些文件**不是模板**，是用同一展现样式填充的不同 demo 数据，用于：
- 演示数据格式
- 测试渲染
- 教学 / onboarding

## 当前文件

| 文件 | 性质 | 状态 |
|------|------|------|
| `cavi-report-v1-cn-demo.html` | 中文 demo（电动车 SUV 数据）| 保留作参考 |
| `README.md` | 本文件 | - |

## 与 templates/ 的区别

- `templates/`：**正式 HTML 模板**（每个文件对应一种渲染载体/展现样式）
- `_demo/`：**数据样例**（用模板填充的不同 demo 数据）

## 规则

- 这里的文件**不参与生产部署**
- 不放真实车型数据（避免误上线）
- 真要演示某个车型，复制这里的结构替换数据即可
