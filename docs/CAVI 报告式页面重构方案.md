# CAVI 报告式页面重构方案

**文档版本**：v1.0
**创建日期**：2026-08-27
**目的**：把"车系详情页"改造成"购车决策报告"
**依据**：`购车手册/20260827-142004.jpeg`（Autocava CAVI 报告范式）

---

## 一、核心结论

> **报告 ≠ 详情页。**
> 详情页是"陈列信息让用户自己读"；报告是"先给结论，再用数据支撑，每个章节有判定"。
> 用户来到 CAVI 报告，30 秒内要回答 3 个问题：
> 1. **值不值得买？**（CAVI 指数 + 一句话）
> 2. **要花多少钱、怎么买？**（现价 + 金融方案对比）
> 3. **跟同价位对手比怎么样？**（3 个直接竞品并排）

参考图（CAVI 范式）用 8 个章节回答这 3 个问题；当前 `zh.html` 用 9 个 Tab 罗列了"参数/金融/卖点/口碑/成本/保障/竞品/选购"，**结构像、形态错**——每个 Tab 都是"卡 + 列表 + Tag"，没有"指数/判定/对比表"。

---

## 二、报告 vs 详情页 · 5 个本质差异

| # | 维度 | 详情页（现在） | 报告（CAVI 范式） |
|---|------|----------------|-------------------|
| 1 | **首屏** | 车名 + 3 个 stat + 价格 | 车名 + **CAVI 指数** + **一句结论** + 3 个核心数据 + 价格 |
| 2 | **价格章** | 一个总价 + 月供 | **经销商现价** + **银行方案** + **厂家金融** + **置换补贴**（4 列并排） |
| 3 | **卖点章** | Tag 列表 | **3-4 个核心数据指标**（大数字+标签）+ 一段洞察描述 |
| 4 | **口碑章** | 3-5 条评论卡 | **CAVI 指数** + **一句洞察** + 3 个维度细分（速度/质量/价值） |
| 5 | **竞品章** | 卡片堆叠 + 1 张表格 | **3 张并排卡片**（本品高亮）+ 全文对比表 |
| 6 | **CTA** | 底部固定 WhatsApp+电话 | **3 个入口**：获取方案/预约试驾/访问官网 |

**根因**：详情页是"导购工具"，报告是"决策辅助"。用户场景完全不同——

- 详情页用户：还在逛、比价、看车
- 报告用户：已经锁定车型，**正在下决定要不要出手**

报告的关键体验：**每章都有"判定"**，没有一段是纯陈述。

## 四、每章的内容维度 + 呈现方式

### 4.1 概览（EXPERTO · 一眼看值不值得买）

**目的**：30 秒给出"值/不值"的判定

**内容维度**：
1. **CAVI 综合指数**（0-5 分，大圆展示）
2. **一句结论**（用户视角的价值判断，如"产品力均衡，家用用户综合价值更突出"）
3. **3 个核心数据**（车辆最关键的 3 个参数：续航/动力/快充 或 马力/油耗/质保）
4. **定位短句**（如"经济实用型轿车 · 城市通勤首选"）

**呈现方式**：
```
┌─────────────────────────────────────┐
│  [徽章] EXPERTO · 一眼看值          │
│  Nissan Versa 2026                  │
│  一句结论（28-32px 加粗）            │
│  定位短句（14px 灰色）               │
│  ┌────┬────┬────┐                   │
│  │CAVI│核心│核心│核心                │
│  │4.5 │数据│数据│数据                │
│  └────┴────┴────┘                   │
└─────────────────────────────────────┘
```

**关键数据点**（基于参考图）：
- CAVI 指数 = 4.05（与原 4.5 区分，CAVI 是经过用户行为验证的综合分）
- 核心数据：续航 510km / 动力 487hp / 电池 80.2kWh / 快充 800V（电动车版式）
- 燃油车版式：马力 118HP / 油耗 5.3L/100km / 质保 3年10万km

---

### 4.2 价格与金融方案

**目的**：回答"要花多少钱、怎么买"

**内容维度**：
1. **经销商现价**（大字，参考图 $869,900）
2. **银行方案月供**（含年利率）
3. **厂家金融月供**（含年利率 + 0 利率标签）
4. **置换补贴**（旧车置换额外补贴）
5. **贷款材料清单**（5-6 项，参考图底部）
6. **CTA：获取个性化方案**

**呈现方式**：
```
┌──────────┬──────────┬──────────┬──────────┐
│ 经销商现价│ 银行方案 │ 厂家金融 │ 置换补贴 │
│ ¥144,400 │ ¥2,873/月│ ¥2,899/月│ ¥3,000   │
│ Performance│ 年利率X% │ 0利率方案│ 旧车最高  │
│   AWD    │ 60%贷款  │ 60%贷款  │  ¥3,000  │
└──────────┴──────────┴──────────┴──────────┘
┌─ 申请贷款所需材料 ─────────────────────┐
│ ☑ 身份证  ☑ 收入证明  ☑ 住址证明  ...   │
└────────────────────────────────────────┘
[ 申请贷款 · 获个性化方案 ]
```

**关键数据点**：
- 现价、月供、年利率、贷款比例、首付要求
- 厂家金融的"0 利率"或"贴息"标签
- 置换补贴的"以旧换新"流程

---

### 4.3 核心卖点

**目的**：用 3-4 个关键数据讲清"为什么是它"

**内容维度**：
1. **3-4 个核心数据指标**（大数字+短标签）
2. **1 段洞察描述**（配大图，约 50-80 字）
3. **可选**：1 句"试驾印象"或"用户高频提到"的话

**呈现方式**：
```
┌──────┬──────┬──────┬──────┐
│ 510km│ 487hp│80.2kW│ 800V │
│ 续航  │ 动力  │ 电池  │快充  │
└──────┴──────┴──────┴──────┘
┌─────────────────────────────────────┐
│ [大图]                                │
│ 空调也不孤单，甚至出行时少吸点烟    │
│ 一段 50-80 字的洞察描述...            │
└─────────────────────────────────────┘
```

**关键数据点**（按车型类型选 3-4 个）：
- **电动车**：续航/动力/电池/快充电压
- **燃油车**：马力/扭矩/油耗/质保里程
- **混动车**：综合油耗/纯电续航/系统综合功率/电池容量

---

### 4.4 用户口碑评价（CAVI 指数）

**目的**：用第三方视角验证"用户买完觉得怎么样"

**内容维度**：
1. **CAVI 指数**（参考图 4.05，大字展示）
2. **一句洞察**（如"产品力均衡，家用用户综合价值更突出"）
3. **3 个维度细分**（速度/质量/价值，每个有子分数 + 评论数）
4. **可选**：3-5 条精选评论（参考图没放，可选）

**呈现方式**：
```
┌─────────────────────────────────────┐
│ 用户口碑评价（CAVI 指数）            │
│ ┌────────┐  产品力均衡，家用用户     │
│ │  4.05  │  综合价值更突出            │
│ │基于X条 │  短洞察描述...            │
│ └────────┘                           │
├─────────────────────────────────────┤
│ 速度：4.X  ·  质量：4.X  ·  价值：4.X│
│ 优秀  ·  良好  ·  一般               │
└─────────────────────────────────────┘
```

**关键数据点**：
- CAVI 综合指数（与首屏一致）
- 维度：通常 3 个——速度(Performance)/质量(Quality)/价值(Value)
- 每维度评分 + 评价人数

### 4.5 用车成本

**目的**：让用户知道"买完之后每年要花多少"

**内容维度**：
1. **年度总成本**（大数字）
2. **5 项并列明细**：燃料 / 保险 / 维护 / 折旧 / 购置税
3. **每项的金额 + 占比 + 简短说明**
4. **省钱建议**（2-3 条）

**呈现方式**：
```
┌─────────────────────────────────────┐
│ 用车成本                    $7,280/年│
│ 以下数据基于15,000km/年计算          │
├──────┬──────┬──────┬──────┬─────────┤
│ 燃料 │ 保险 │ 维护 │ 折旧 │ 购置税   │
│$2,766│$1,749│$1,512│$1,266│ $?     │
└──────┴──────┴──────┴──────┴─────────┘
[省钱建议：xxx · xxx · xxx]
```

**关键数据点**：
- 5 项：Fuel / Insurance / Maintenance / Depreciation / Tax（可按市场调整）
- 每项金额 = 月度 × 12
- 总额 = 5 项之和

---

### 4.6 购车保障与服务覆盖

**目的**：让用户知道"买了之后出问题怎么办"

**内容维度**：
1. **质保里程**（大字，如 7 年 / 120,000 km）
2. **保养含**（如 12 次 / 24,000 km）
3. **支持项目清单**（3-4 项 Tag）
4. **服务网络覆盖**（如 1,500+ 网点）

**呈现方式**：
```
┌──────────────┬──────────────┐
│  质保         │  保养含       │
│7年/120,000km│12次/24,000km│
├──────────────┴──────────────┤
│ [全车保修] [电池保修]        │
│ [软件OTA] [24h 道路救援]     │
└─────────────────────────────┘
```

**关键数据点**：
- 整车质保年限 + 里程
- 电池质保（电动车专属）
- 保养包次数 + 里程
- 服务网络规模
- 24h 道路救援

---

### 4.7 主要竞品怎么选

**目的**：让用户一眼看到"同价位还有什么选"

**内容维度**：
1. **3 个直接竞品**（价格段 ±10%）
2. **每竞品一张卡**：车图 + 名称 + 起售价 + 月供 + 一句"适合谁"
3. **本车高亮**（边框 + 顶部"本品"标签）
4. **全文对比表**（5-6 个核心维度）

**呈现方式**：
```
┌─────────────┐
│  本品        │
│ [G6 车图]   │
│ 比亚迪 G6    │
│ ¥185,800起  │
│ ¥2,560/月   │
│ 适合:家用均衡│
└─────────────┘
┌─────────────┐ ┌─────────────┐
│ MODEL Y     │ │ EV6         │
│ ¥296,000    │ │ ¥264,500    │
│ ¥3,500/月   │ │ ¥3,200/月   │
│ 适合:品牌   │ │ 适合:性能   │
└─────────────┘ └─────────────┘
┌─ 全文对比表 ──────────────────────────┐
│ 项目   │G6   │MODEL Y│EV6            │
│ 价格   │✓最低│        │              │
│ 续航   │      │✓      │              │
│ 加速   │      │       │✓             │
└────────────────────────────────────────┘
```

**关键数据点**：
- 竞品选择：3 个直接对标（价格段 ±10%）
- 每竞品：起售价 + 月供 + 一句定位
- 全文对比表：5-8 个核心维度，每个维度标记"谁最优"

---

### 4.8 想进一步了解？（CTA 行动入口）

**目的**：让用户从"了解"变成"动作"

**内容维度**：
1. **3 个明确 CTA**：
   - 获取个性化方案
   - 预约试驾
   - 访问官网
2. **每个 CTA：图标 + 标题 + 短描述 + 价格/时长（如 ¥XX/月 · 60s 申请）**

**呈现方式**：
```
┌─────────────────────────────────────┐
│ 想进一步了解？选择一种方式            │
├──────────┬──────────┬───────────────┤
│ 获取方案  │ 预约试驾  │ 访问官网       │
│ ¥XX/月   │ 30min    │ autocava.com  │
│ 60s 申请  │ 周末可约  │ 立即访问       │
└──────────┴──────────┴───────────────┘
```

**关键数据点**：
- 3 个 CTA 与底部固定栏的"WhatsApp/电话"互补
- 每个 CTA 有可量化预期（时长/价格/到达率）
